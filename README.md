# Load Balancer Simulator – DSA Project

## Description
A C++ based project that distributes incoming requests among multiple servers using Round Robin and Least Loaded algorithms. It manages server workloads and waiting requests using different DSA concepts.

## Features
- Add and remove servers
- Add and complete requests
- Round Robin scheduling
- Least Loaded scheduling
- Waiting queue management
- Server status and overload detection
- Assignment history
- Min-Heap visualization

## DSA Concepts Used
- Vector
- Queue
- Priority Queue (Min-Heap)
- Linear Search
- Sorting
- Round Robin Algorithm

## Technologies Used
- C++
- Visual Studio Code

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the code:

```bash
g++ dsa.cpp -o dsa
```

4. Run the program:

```bash
./dsa
```

On Windows PowerShell, use:

```powershell
.\dsa.exe
```
